# 多标的对比分析报告 — 设计方案

> 说明：本文是历史设计草案，当前实现已改为“研究复盘与观察框架”口径。所有对比结论只做相对证据排序，不构成任何买卖建议。

> 设计原则：**专业数据 + 说人话的解释**。每个专业指标旁边都有一句让金融小白看得懂的解读。

---

## 一、入口设计

### 使用方式

```bash
# 多只股票对比
python3 run_analysis.py 贵州茅台 五粮液 泸州老窖

# 多只ETF对比
python3 run_analysis.py 510300 510500 159915

# 混合对比（A股+港股）
python3 run_analysis.py 比亚迪 00175.HK
```

### 路由逻辑

```
输入 1 个参数 → 走现有的单标的分析（不变）
输入 ≥2 个参数 → 进入对比模式
最多 5 个 → 超过 5 个提示"最多同时对比5只"
```

### 自动判断对比类型

```python
types = [identify(code) for code in inputs]
if all(t == "etf"):       → ETF对比报告
elif all(t == "stock"):   → A股对比报告
elif all(t == "hk_stock"):→ 港股对比报告
else:                     → 跨类型/跨市场对比报告（提取共有指标）
```

### 输出文件命名

```
贵州茅台_vs_五粮液_vs_泸州老窖_对比分析报告_20260509.pdf
```

## 二、股票对比报告结构（10章）

> 行业依据：CFI Comps Table、FINRA 估值指标、WallStRank Peer Comparison、
> Goodwill Wealth 四维对比体系、DuPont 分析框架

### 章节 1：对比概览

**专业内容**：基本信息一览表

| | 贵州茅台 | 五粮液 | 泸州老窖 |
|--|---------|--------|---------|
| 行业 | 白酒 | 白酒 | 白酒 |
| 市值 | 2.1万亿 | 4800亿 | 2100亿 |
| 上市时间 | 2001年 | 1998年 | 1994年 |
| 总营收 | 1505亿 | 832亿 | 302亿 |

**说人话解读**：
> 三家公司都是白酒行业的头部企业。茅台的"体量"最大——如果把它们比作三家餐厅，
> 茅台是全国连锁的五星级酒店，五粮液是省会的高端餐厅，泸州老窖是地级市的名店。

---

### 章节 2：模型对比研究解读

**专业内容**：相对证据排序 + 各自优劣势 + 研究假设

**AI Prompt 要求**：
1. 先给出证据强弱排序，并说明排序依据
2. 用 2-3 句话说清每家的核心优势和风险
3. 解释为什么排这个顺序（结合估值、增速、盈利质量）
4. 用比喻或生活化语言，不输出直接交易动作

**说人话示例**：
> 茅台像银行定存——稳定、确定、但增速慢；五粮液像理财产品——回报不错、风险适中；
> 泸州老窖像成长型基金——弹性大、但波动也大。

---

### 章节 3：股价走势叠加

**专业内容**：归一化涨跌幅曲线（近1年）

**说人话解读**：
> 如果把三家公司放在同一时间窗口观察：
> - 茅台：变成了 10,800 元（赚了 8%）
> - 五粮液：变成了 9,500 元（亏了 5%）
> - 泸州老窖：变成了 11,200 元（赚了 12%）

---

### 章节 4：估值对比

**专业内容**：P/E、P/B、P/S、EV/EBITDA 柱状图+表格

**每个指标旁的说人话**：
- **PE（市盈率）**：假设你花钱买下整家公司，靠它每年的利润需要多少年回本。PE=25 表示"25年回本"。越低越"便宜"，但要结合增速看。
- **PB（市净率）**：公司的"市场价"是"家底"的几倍。PB=8 表示市场觉得这家公司值它家底的 8 倍，说明大家很看好它。
- **PS（市销率）**：市值除以年销售额。PS=10 表示市场愿意为它 1 年的收入付 10 倍的价格。
- **EV/EBITDA**：投行最爱用的指标——比 PE 更公平，因为排除了"借了多少钱"和"交了多少税"的干扰。数字越低越"便宜"。

**说人话总结**：
> 从"性价比"来看，泸州老窖最便宜（PE最低），茅台最贵（PE最高）。
> 但茅台贵有贵的道理——增速虽然不是最快，但最确定，就像买iPhone虽然贵但不容易踩坑。

---

### 章节 5：成长性对比

**专业内容**：营收增速、净利增速柱状图（近3年趋势）

**说人话解读**：
- **营收增速**：今年比去年多卖了多少钱。好比一家奶茶店去年卖100万今年卖120万，增速就是20%。
- **净利增速**：扣掉所有成本后，今年比去年多赚了多少。增速高说明"越来越能赚钱"。

**说人话总结**：
> 三家都在增长，但速度不同：泸州老窖跑得最快（好比年轻人在追赶），
> 茅台速度中等但非常稳（好比中年人步伐稳健），五粮液最近慢了（需要关注原因）。

---

### 章节 6：盈利质量对比

**专业内容**：ROE（含 DuPont 拆解）、毛利率、营业利润率、净利率

**每个指标旁的说人话**：
- **ROE（净资产收益率）**：股东每投入100元，一年能赚多少。ROE=30% 表示"投100赚30"，非常优秀。
- **DuPont 拆解**——ROE 可以拆成三个部分理解：
  - **净利率**：每卖100元能剩下多少利润（赚钱能力）
  - **资产周转率**：一年能把手里的钱用几遍（效率）
  - **权益乘数**：借了多少倍的钱来做生意（杠杆）
  - 好比开店：净利率是"每杯奶茶赚多少"，周转率是"一天卖几杯"，杠杆是"借了多少钱开店"。
- **毛利率**：卖一件东西，扣掉原材料成本后剩多少。白酒行业毛利率90%意味着"一瓶卖1000元的酒，原材料才100元"。

---

### 章节 7：财务健康度对比

**专业内容**：资产负债率、利息覆盖倍数、经营现金流/净利润

**每个指标旁的说人话**：
- **资产负债率**：公司有多少钱是借的。50%意味着"家底的一半是借来的"。低了安全但保守，高了进取但有风险。
- **利息覆盖倍数**：赚的钱是利息支出的几倍。10倍意味着"赚的钱还10遍利息都够"，很安全。低于2倍就危险了。
- **经营现金流/净利润**：利润是不是"真金白银"。有些公司账面赚钱但钱收不回来（类似你卖东西赊账了）。这个比值 >1 说明赚的都是真钱。

---

### 章节 8：分红与股东回报

**专业内容**：股息率、分红比例、近3年分红趋势

**说人话解读**：
- **股息率**：按当前价格估算的年度现金分红比例。股息率2%意味着名义上每10万元市值对应约2000元年度分红。
- **分红比例**：公司赚的钱里拿多少出来分。比例高说明公司大方，比例低可能是把钱留着扩大生产。

---

### 章节 9：资金面对比（仅A股）

**专业内容**：主力资金流向、融资融券、股东人数变化

**说人话解读**：
- **主力资金净流入**：反映一段时间内大额资金流向，可作为风险偏好变化的观察线索。
- **股东人数变化**：持股人数增加可能意味着筹码分散，减少可能意味着筹码集中，但需要和成交额、价格与基本面交叉验证。

---

### 章节 10：综合评分表

**专业内容**：多维度量化打分

```
              贵州茅台   五粮液   泸州老窖
估值性价比     ⭐⭐⭐      ⭐⭐⭐⭐    ⭐⭐⭐⭐⭐
成长性         ⭐⭐⭐      ⭐⭐⭐      ⭐⭐⭐⭐
盈利质量       ⭐⭐⭐⭐⭐  ⭐⭐⭐⭐    ⭐⭐⭐⭐
财务健康       ⭐⭐⭐⭐⭐  ⭐⭐⭐⭐    ⭐⭐⭐⭐
分红回报       ⭐⭐⭐⭐    ⭐⭐⭐⭐    ⭐⭐⭐
资金面信号     ⭐⭐⭐⭐    ⭐⭐⭐      ⭐⭐⭐⭐
──────────────────────────────────────
综合得分       88         76         82
```

**说人话总结**：
> 打个比方：茅台是"优等生"——门门都好但价格贵（估值高）；泸州老窖是"进步最快的学生"——
> 成绩提升快、价格合理，但稳定性不如茅台；五粮液是"中等偏上"——各方面都不差，但没有突出亮点。

## 三、ETF 对比报告结构（10章）

> 行业依据：SSGA 6步评估法、StableBread 三维评估体系、晨星 Morningstar 风险调整后收益评级

### 章节 1：基金概览

**专业内容**：名称/代码/跟踪指数/基金公司/成立日期/规模

**说人话解读**：
> ETF 可以理解为跟踪一篮子资产的工具。510300 对应 A股最大的300家公司，510500 对应排名301-800的中型公司，两者指数暴露和波动特征不同。

### 章节 2：模型对比研究解读

同股票，但侧重回答：
- 哪个赛道当前证据更充分
- 同赛道产品在费率、跟踪质量、规模和流动性上的差异
- 适合用什么观察框架继续跟踪

### 章节 3：走势叠加图

**说人话**：同股票，观察同一时间窗口下的相对表现。

### 章节 4：收益率对比

**专业内容**：近1月/3月/6月/1年/3年 收益率柱状图

**说人话解读**：
- **近1年收益率**：基金过去一年净值变化百分比。
- **年化收益率（3年）**：把三年表现折算为平均每年的变化，适合观察较长周期特征。

### 章节 5：风险指标对比

**专业内容**：波动率、最大回撤、夏普比率

**每个指标旁的说人话**：
- **波动率**：价格上蹿下跳的剧烈程度。波动率高 = 坐过山车，波动率低 = 坐普通列车。
- **最大回撤**：从阶段最高点到最低点的最大跌幅。-20%意味着历史区间内曾从高点回落约两成。
- **夏普比率**：每承受1份风险换来多少收益。夏普比率 >1 = 赚到的比冒的险多，值得。<0 = 冒了险还亏钱。

### 章节 6：跟踪效率对比

**专业内容**：跟踪误差 + 跟踪偏离

**说人话解读**：
> ETF 的本质是"复印机"——它的工作是精确复制指数的走势。跟踪误差就是"复印的清晰度"：
> - 误差 <0.5%：复印得很清楚（优秀）
> - 误差 0.5-1%：有点模糊但还行（合格）
> - 误差 >1%：复制偏差需要重点复核

### 章节 7：成本对比

**专业内容**：管理费/托管费/总费率

**说人话解读**：
> 费率就是"管理费"——基金公司每年从你的收益里扣掉的服务费。
> 0.5%和0.15%看起来差别小，但投10万持有10年，差距能到3000-5000元。
> 在指数暴露和跟踪质量相近时，费率越低通常越有成本优势。

### 章节 8：流动性对比

**专业内容**：日均成交量/基金规模/折溢价率

**说人话解读**：
- **日均成交量**：每天有多少成交活动。量大通常意味着成交体验更稳定，量小可能带来价差和冲击成本。
- **基金规模**：基金管了多少钱。规模太小（<2亿）有被清盘的风险（基金公司觉得不赚钱就关了）。
- **折溢价率**：市场交易价格和基金实际净值的偏差。接近0通常更稳定，显著溢价意味着价格容错较低。

### 章节 9：持仓分析对比

**专业内容**：行业分布饼图 + 前十大重仓股

**说人话解读**：
> ETF 背后是一篮子成分证券。这页用于观察指数暴露、行业结构和集中度。
> 比如 510300 的前三大持仓若包含贵州茅台、宁德时代、中国平安，说明该 ETF 对这些权重股的波动较敏感。

### 章节 10：综合评分

同股票风格，用星级打分 + "说人话总结"。

## 四、跨类型/跨市场对比处理

### 提取共有指标

当对比标的不全是同类型时（如 A股 + 港股），只对比两者都有的指标：
- 估值：PE / PB / 市值
- 成长：营收增速 / 净利增速
- 盈利：ROE / 毛利率 / 净利率
- 风险：资产负债率 / 现金流比率
- 走势：归一化叠加图

### AI Prompt 中加入风险提示

```
注意：这些标的分属不同市场（A股/港股），存在以下不可比因素：
1. 会计准则差异（中国准则 vs 国际准则）
2. 税率差异（港股无资本利得税）
3. 交易制度差异（港股T+0、无涨跌停）
4. 汇率影响（港元 vs 人民币）
请在分析中说明这些差异对对比结论的影响。
```

## 五、"说人话"原则总结

### 每个章节的固定结构

```
┌────────────────────────────────────┐
│  📊 专业数据（表格/图表）          │
│     PE: 25.3  |  PB: 8.1  | ...   │
├────────────────────────────────────┤
│  💡 这意味着什么？                  │
│  用生活化的语言解释每个指标含义      │
├────────────────────────────────────┤
│  📝 小结                           │
│  一句话说清楚"所以哪个更好、为什么"  │
└────────────────────────────────────┘
```

### AI Prompt 中的通俗化指令

```
你是一位经验丰富的投资顾问，正在向一位完全没有金融背景的朋友解释分析结果。

规则：
1. 每个专业术语第一次出现时，用一句话解释其含义
2. 多用比喻和生活化类比（如"开店""存银行""买手机"）
3. 避免使用以下词汇而不解释：alpha、beta、夏普、EV、EBITDA
4. 结论要明确："如果让我选一个，我选XX，因为..."
5. 风险提示要具体："最大的风险是XX，最坏情况下可能亏XX%"
```
